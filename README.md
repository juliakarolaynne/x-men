# Painel Interativo de Personagens — X-Men

Aplicação web temática e interativa inspirada no universo dos X-Men, demonstrando conceitos fundamentais de manipulação do DOM e estilização dinâmica com CSS e JavaScript.

🔗 **Acesse o projeto online:** [juliakarolaynne.github.io/x-men](https://juliakarolaynne.github.io/x-men)

---

## 📌 Sobre o Projeto

O usuário pode navegar interativamente pela galeria de mutantes:
- **Seleção Dinâmica via Hover:** ao passar o cursor sobre qualquer card da lista, o personagem em destaque é atualizado em tempo real.
- **Transição de Conteúdo:** troca instantânea de imagem em alta resolução, nome e descrição com efeitos visuais fluidos.
- **Suporte Mobile:** ajuste automático de rolagem e posicionamento adaptado para telas menores.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** estrutura semântica com uso de `data-attributes` para armazenamento de dados no próprio markup.
- **CSS3:** estilização modularizada (`reset.css`, `estilos.css`, `responsivo.css`), sombras e transições.
- **JavaScript (ES6+):** eventos de mouse (`mouseenter`), seleção de nós do DOM e manipulação de classes CSS.

---

## 🚀 Como Executar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/juliakarolaynne/x-men.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd x-men
   ```
3. Abra o arquivo `index.html` no seu navegador.
